# Seguridad

Para informar una vulnerabilidad, no abras una incidencia pública. Escribí a `estudiodcrea@gmail.com` con la página afectada, una descripción reproducible y el impacto observado.

No envíes contraseñas, tokens, datos personales de terceros ni pruebas destructivas. El sitio no requiere secretos en el navegador; cualquier credencial futura debe almacenarse como secreto del repositorio y nunca dentro de `src/site/`.
