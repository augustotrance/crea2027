# Cómo colaborar

1. Crear una rama corta desde `main`.
2. Hacer cambios únicamente en `src/site/`, `scripts/`, `tests/` o `docs/`; nunca editar `dist/`.
3. Mantener los textos en español y evitar afirmaciones, resultados o datos de contacto sin verificar.
4. Optimizar imágenes a WebP y usar nombres descriptivos en minúsculas, separados por guiones.
5. Incluir `alt`, `width` y `height` en cada imagen de contenido.
6. Ejecutar `npm run check`, `npm test` y `npm run build`.
7. Abrir una solicitud de cambios explicando intención, alcance y páginas afectadas.

Los cambios visuales deben verificarse, como mínimo, en 360 px, 768 px y 1440 px de ancho, con teclado y con la preferencia de movimiento reducido.
